# backend/

The Linaw backend (speech-to-text + Ollama) goes here, in whatever language the backend team chooses.

It must serve the contract on `ws://localhost:8765`. Start with **[docs/backend.md](../docs/backend.md)**, which covers the message flow, how to generate types from the JSON Schema, and how to check your server with `pnpm conformance`.

Replace this file with your own setup and run instructions.
